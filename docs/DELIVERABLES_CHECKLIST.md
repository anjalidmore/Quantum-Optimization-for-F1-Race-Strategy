## How to regenerate everything

```bash
python scripts/build_all.py --force     # every artifact above, Tasks 1-9 + quantum
pytest -q                               # the test suite
./run.sh                                 # backend + dashboard
```

The most recent full run of both is recorded in [`TESTING_REPORT.md`](TESTING_REPORT.md):
all 10 build stages passed and 284 tests passed, with no metric changed by the rebuild.
